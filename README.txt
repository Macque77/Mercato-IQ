========================================
MERCATO IQ WEBSITE - COMPLETE PACKAGE
========================================

This package contains everything you need to deploy your transfer analytics website.

FOLDER STRUCTURE:
- engine/: Python automation scripts
  - aggregate.py: Aggregates club data into landing pages
  - build_extended.py: Builds HTML from templates + data
  - watch.py: Monitors files for changes
- clubs/: Your transfer data files (.data.js)
- index.html: Global splash page template
- template-nation.html: Nation landing page template
- template-league.html: League landing page template
